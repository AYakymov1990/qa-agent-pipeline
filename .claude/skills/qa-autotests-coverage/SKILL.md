# Покриття регресу автотестами

Мета — не дублювати агентом і вручну те, що перевіряють автотести, і заздалегідь знати, які автотести впадуть через зміну.

## Джерела

- Проєкт автотестів — `$AUTOMATION_PATH`, **тільки читання** (правки — тільки `qa-autotests-update` в окремій гілці).
- Карта автотестів — `$CODEWIKI_PATH/kb/QA/autotests-map.md` (структура проєкту, категорії, запуск, «зона → тести»). Немає або застаріла (коміт у шапці ≠ `HEAD`) — побудуй / онови за `templates/autotests-map.md` і запропонуй як правку в CodeWiki (`qa-context-update`).
- Гілка розробника — `$AVTOPRO_PATH`: `git --no-optional-locks diff master...<гілка> --stat` і потрібні файли (тільки читання; гілку з `input/task.md`).
- Рядки `[Регресс]` і Regression List задачі (`input/task.md`).

## Що зробити

Для кожної зони регресу:

1. **Знайди тести** — за картою, потім пошуком за компонентами, сторінками, URL, ендпоінтами, текстами UI.
2. **Прочитай тест**, не тільки назву: кроки, assert, площадка, роль.
3. **Покриття**: повне / часткове (чого бракує) / немає.
4. **Чи зламає зміна тест** — тест перевіряє поведінку, яку гілка змінила (текст, порядок полів, шлях, ліміт): «потребує оновлення» → `qa-autotests-update`.
5. Запиши в чек-лист:
    ```bash
    .venv/bin/python scripts/checklist.py set --task <ID> CHK-060 autotests=covered exec=автотести "why=Checkout/ContactFormTests::FieldOrder"
    .venv/bin/python scripts/checklist.py set --task <ID> CHK-062 autotests=partial "why=тест є, тултип не перевіряє"
    ```
    Часткове чи немає — `exec` за звичайними правилами (агент / вручну).

## Вихід

`tasks/<ID>/autotests-coverage.md` за `templates/autotests-coverage.md`: зони і тести (`файл::Тест`), покриття, «Що запустити» (команда — тільки з карти, README або CI проєкту), «Прогалини», «Тести, які потребують оновлення» (з посиланням на зміну в гілці). Рядок у `pipeline.md`.

## Правила

- Покриття — тільки за тим, що тест реально перевіряє (assert).
- Тут тести не пишемо і не правимо.
- Секрети з конфігів автотестів (паролі, токени, рядки підключення) нікуди не переносити.
