# Задачі

Одна папка на задачу Azure DevOps: `tasks/<ID>/`.

```
tasks/<ID>/
├── input/                 кеш з Azure DevOps (не комітиться, отримується заново)
│   ├── task.md            задача: поля, опис, критерії, звʼязки, гілка розробника
│   ├── comments.md        коментарі
│   ├── checklist.xlsx     вкладений чек-лист — оригінал
│   └── ado-sync.md        ревізія, коли отримано
├── checklist.json         розібраний чек-лист (скрипт)
├── checklist.md           розібраний чек-лист + класифікація: агент / вручну / API / автотести
├── pipeline.md            маршрут, журнал, «де зупинились»
├── data.md                дані під задачу поверх довідника TD (стенд, особливі дані)
├── autotests-coverage.md  покриття регресу автотестами
├── spec/                  QA-режим: специфікація і кейси (переглядає QA)
│   ├── spec.md
│   ├── recon.md
│   └── cases/TC-*.md
├── runs/
│   └── <YYYYMMDD-HHMM>-<qa|dev>-<user>/
│       ├── selection.md   які перевірки взято і чому
│       ├── cases/         dev-режим: згенеровані кейси
│       ├── results.json   результат по кожному CHK
│       ├── report.md / report.html / metrics.md
│       ├── checklist-<прогін>.xlsx   копія чек-листа з колонкою «Прогон N»
│       └── TC-xxx/*.png   докази
└── bugs/                  QA-режим: чернетки баг-репортів
```
